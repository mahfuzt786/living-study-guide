# How Memory Works — Study Skills Seminar, Week 3

## Key terms
- **Encoding**: the process of turning what you perceive into a memory trace that can be stored.
- **Retrieval**: bringing a stored memory back into conscious awareness.
- **Working memory**: a limited-capacity system that holds and manipulates information for a few seconds while you use it.
- **Long-term memory**: the relatively durable store that holds knowledge and skills for days, years or a lifetime.

## The forgetting curve
Hermann Ebbinghaus published his experiments on memory in 1885.
He memorised lists of nonsense syllables and tested himself after different delays.
Forgetting was fastest in the first hours after learning and then slowed down.
Each review made the material easier to relearn the next time.

## Retrieval practice
Retrieval practice is the strategy of recalling information from memory instead of re-reading it.
The testing effect means that taking a test on material improves later retention more than spending the same time restudying it.
Roediger and Karpicke reported the testing effect for prose passages in 2006.
Low-stakes quizzes count as retrieval practice; the grade does not matter.

## Spacing and interleaving
The spacing effect is the finding that study sessions spread out over time produce better long-term retention than one massed session.
Cramming is massed practice.
Interleaving means mixing different topics or problem types within one study session.
Interleaving feels harder than blocked practice, and that difficulty is part of why it works.

## The Leitner system
The Leitner system is a flashcard method that uses numbered boxes to schedule reviews.
Sebastian Leitner described it in 1972.

How to run a Leitner review session:
1. Put every new card in Box 1.
2. Review Box 1 every day, Box 2 every few days and Box 3 once a week.
3. When you answer a card correctly, move it up one box.
4. When you get a card wrong, move it back to Box 1.

## Working memory limits
George Miller's 1956 paper described a span of about seven items, plus or minus two.
Later research by Nelson Cowan suggests the limit is closer to four chunks.
Chunking is grouping separate pieces of information into larger, meaningful units.
